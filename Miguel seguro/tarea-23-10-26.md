# Informe de aprendizajes

## 1. ¿Qué trabajé?

Durante este trabajo me enfoqué en el rediseño de la sección *Nosotros* de la página web corporativa de Enjamer. El objetivo principal fue organizar mejor la información de la empresa, ya que la página anterior contenía demasiados elementos en una sola sección.

La propuesta consistió en dividir la información en diferentes páginas independientes: la presentación principal de Enjamer, el propósito, el origen de su nombre, los valores y los principios de la empresa. Para facilitar el acceso a estas páginas, también se planteó una nueva forma de navegación mediante un menú desplegable en la opción *Nosotros* de la barra de navegación.

Además, el trabajo tuvo en cuenta el diseño visual de Enjamer, la reutilización de componentes existentes, las animaciones entre páginas y la adaptación del sitio a dispositivos móviles.

Al desarrollar esta actividad, comprendí que organizar correctamente la información de una página web es importante para que los usuarios puedan encontrar lo que necesitan sin tener que recorrer grandes cantidades de contenido.

## 2. ¿Qué aprendí durante el desarrollo?

### a) Cómo mejorar la navegación de una página web

Aprendí que la navegación es una parte fundamental de cualquier sitio web, porque permite que los usuarios encuentren la información de manera rápida y sencilla.

En este caso, se planteó que la opción *Nosotros* continuara llevando a la página principal de presentación de Enjamer, pero que también permitiera acceder a las páginas de Propósito, Nuestro nombre, Valores y Principios mediante un menú desplegable.

También comprendí que un menú debe ser fácil de utilizar y mantener un comportamiento adecuado cuando el usuario pasa el cursor sobre sus opciones o selecciona una de ellas. Esto es importante para evitar que el menú se cierre inesperadamente y dificulte la navegación.

### b) Cómo organizar mejor el contenido de una página

Uno de los principales aprendizajes fue entender la importancia de dividir la información según el tema que se quiere presentar.

En lugar de mantener todos los contenidos de la empresa en una sola página, se propuso crear páginas independientes para cada tema. De esta manera, la presentación principal de Enjamer puede concentrarse en explicar quiénes somos, mientras que las demás páginas profundizan en aspectos específicos de la empresa.

También aprendí que cada página debe tener un título principal y una estructura clara para que el usuario pueda identificar fácilmente el contenido que está consultando.

Esta organización permite que el sitio web sea más fácil de recorrer, comprender y mantener.

### c) Cómo reutilizar componentes en React

Aprendí que reutilizar componentes ayuda a evitar la repetición de código y permite mantener un diseño más uniforme en toda la aplicación.

Para esta actividad se planteó utilizar componentes existentes, como TextContentComponent y FooterComponent, en las nuevas páginas de la sección Nosotros.

Además, se propuso crear un componente compartido para presentar los valores y los principios de Enjamer mediante una estructura visual similar a un Roadmap. Este componente recibiría la información mediante propiedades (*props*), lo que permitiría cambiar el contenido sin tener que crear dos implementaciones diferentes.

Con esto comprendí que un componente reutilizable no solo sirve para ahorrar código, sino también para facilitar futuras modificaciones y mantener una estructura más organizada.

### d) Cómo utilizar React Router para crear páginas independientes

Durante esta actividad profundicé en la importancia de utilizar React Router para organizar la navegación entre diferentes páginas de una aplicación desarrollada con React.

La propuesta requiere que cada sección de Nosotros tenga su propia ruta, de modo que el usuario pueda acceder directamente a ellas y cambiar de una página a otra sin necesidad de recargar todo el sitio.

También comprendí que es importante conservar el funcionamiento normal del navegador, incluyendo la posibilidad de regresar a la página anterior mediante el botón de retroceso.

Esto me permitió entender mejor cómo se relacionan las rutas, los componentes y la experiencia de navegación dentro de una aplicación web.

### e) Cómo mantener la identidad visual de una empresa

Otro aprendizaje importante fue comprender que el diseño de una página corporativa debe representar la identidad de la empresa y mantener una apariencia coherente en todas sus secciones.

En el caso de Enjamer, se tomó como referencia el manual de identidad corporativa y el prototipo de la sección Nosotros. Estos materiales sirven para orientar el uso de los colores, la tipografía, los espacios y los elementos visuales.

También se tuvo en cuenta que cada página puede tener una composición diferente sin perder la relación con el resto del sitio web.

Esto me ayudó a comprender que diseñar una página no significa solamente escoger colores o acomodar elementos, sino mantener una identidad visual que permita reconocer a la empresa.

### f) Cómo mejorar la experiencia en dispositivos móviles

Aprendí que una página web debe adaptarse a diferentes tamaños de pantalla y formas de interacción.

En computadores, el menú desplegable puede mostrarse cuando el usuario pasa el cursor sobre la opción *Nosotros*. Sin embargo, en dispositivos móviles es necesario tener en cuenta que la navegación se realiza principalmente mediante toques en la pantalla.

Por esta razón, se planteó incorporar una flecha que permita abrir o cerrar el submenú sin quitar la posibilidad de acceder a la página principal de Nosotros.

También comprendí que es importante evitar que los elementos se superpongan, que el contenido se salga de la pantalla o que los enlaces sean demasiado difíciles de seleccionar.

Esto demuestra que un diseño no debe evaluarse únicamente en un computador, sino también en teléfonos y otros dispositivos.

### g) Cómo trabajar con animaciones y transiciones

Durante la planificación de esta actividad comprendí la importancia de utilizar transiciones para que el cambio entre páginas se sienta más natural.

Cuando un usuario selecciona una opción del menú, el contenido debe cambiar de manera clara y sin movimientos bruscos que puedan afectar la experiencia.

También aprendí que las animaciones deben utilizarse con moderación y mantener un comportamiento coherente con los elementos que ya existen en la página.

El objetivo no es agregar efectos innecesarios, sino conseguir que la navegación sea agradable, fluida y fácil de entender.

### h) Cómo mantener una estructura de código organizada

Esta actividad también me permitió comprender la importancia de organizar los archivos y componentes de acuerdo con su función.

La propuesta contempla mantener los componentes específicos dentro de sus respectivas páginas y ubicar el nuevo componente reutilizable del Roadmap dentro de la carpeta `common/`, siguiendo la convención de nombres establecida para el proyecto.

Además, se busca separar la información de los valores y los principios, aunque ambos utilicen la misma estructura visual.

Con esto entendí que una buena organización facilita encontrar el código, realizar cambios y trabajar en equipo sin afectar innecesariamente otras partes del sitio web.

## 3. ¿Qué aprendí al revisar los requisitos y posibles errores?

Al analizar los requisitos de esta actividad, comprendí que un cambio aparentemente visual puede involucrar diferentes partes de una aplicación.

Por ejemplo, agregar un menú desplegable no consiste únicamente en mostrar una lista de opciones. También es necesario controlar cuándo aparece, cuándo desaparece, cómo se comporta con el mouse y cómo funciona en dispositivos táctiles.

De la misma manera, crear nuevas páginas requiere revisar las rutas, la estructura de los componentes, los títulos principales y la forma en que se mantiene el diseño general del sitio.

También entendí la importancia de considerar los elementos que ya funcionan correctamente. En este caso, se busca conservar el diseño y el comportamiento de la barra de navegación, el footer y el Roadmap original de la página de Inicio.

Esto me enseñó que, antes de realizar cambios, es importante comprender cómo funciona el código existente para evitar errores en otras partes del proyecto.

## 4. ¿Qué decisiones tomé durante el trabajo?

Para organizar esta actividad, se establecieron varias decisiones importantes:

- **Dividir la sección Nosotros:** se planteó separar la información en páginas independientes para evitar que el contenido estuviera demasiado concentrado en un solo lugar.
- **Mantener la navegación principal:** se decidió conservar la función del enlace Nosotros y agregar un menú desplegable para acceder a las demás secciones.
- **Reutilizar componentes existentes:** se propuso aprovechar componentes como TextContentComponent y FooterComponent para mantener la uniformidad del sitio.
- **Crear un Roadmap compartido:** se planteó utilizar un mismo componente para los valores y los principios, cambiando su contenido mediante propiedades.
- **Conservar la identidad visual:** se tomó como referencia el manual de identidad corporativa y el prototipo de Enjamer para orientar el diseño de las nuevas páginas.
- **Adaptar la navegación a móviles:** se consideró necesario agregar un control independiente para expandir y contraer el submenú sin perder el acceso a la página principal.
- **Proteger las secciones existentes:** se estableció que el Roadmap de Inicio, el footer y las demás rutas debían conservar su funcionamiento.

Estas decisiones me ayudaron a comprender que un buen desarrollo requiere pensar no solo en el resultado visual, sino también en la organización del código, la facilidad de uso y el mantenimiento futuro de la aplicación.

## 5. Resultados y evidencias

La actividad se centró en definir y organizar los cambios necesarios para renovar la sección Nosotros de la página corporativa de Enjamer.

Entre los principales resultados esperados de esta propuesta se encuentran:

- Una página principal de Nosotros con una presentación clara de Enjamer.
- Páginas independientes para Propósito, Nuestro nombre, Valores y Principios.
- Un menú desplegable integrado en la barra de navegación.
- Una estructura compartida para presentar los valores y los principios.
- Una navegación organizada mediante React Router.
- Una presentación visual coherente con el manual de identidad corporativa.
- Una experiencia adaptable a computadores y dispositivos móviles.
- La conservación del diseño del footer y del funcionamiento de los componentes existentes.

La comprobación de estos resultados debe realizarse mediante la revisión del código y las pruebas correspondientes, verificando que las rutas, las animaciones, el menú desplegable y los diseños funcionen correctamente.

## 6. Conclusión

Esta actividad me permitió comprender mejor la importancia de organizar la información y la navegación de una página web. Aprendí que una sección corporativa debe presentar el contenido de manera clara, permitir que los usuarios encuentren fácilmente cada tema y mantener una apariencia coherente con la identidad de la empresa.

También reforcé mis conocimientos sobre React, React Router, la reutilización de componentes y la adaptación de interfaces a dispositivos móviles. Además, comprendí que los cambios deben realizarse con cuidado para no afectar las funciones que ya existen en el proyecto.

En general, este trabajo me ayudó a entender que desarrollar una página web no consiste solamente en crear elementos visuales, sino también en pensar en la experiencia del usuario, la organización del código y la facilidad para realizar modificaciones en el futuro.

Me llevo como aprendizaje que **una buena página web debe tener un diseño atractivo, una navegación sencilla y una estructura de código organizada que permita mantenerla y mejorarla con el tiempo**.
